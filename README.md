# OfferDesk · 岗位投递台

把岗位截图、招聘要求和投递进度放在一起，方便随时回看、记录和跟进。

OfferDesk 是一款支持 **Mac 和 Windows** 的个人求职工作台。下载安装后直接打开，无需注册账号；岗位、备注和截图都保存在自己的电脑中。

**[下载 OfferDesk](https://github.com/mzh0221/offerdesk/releases)**

## 下载安装

打开下载页，在版本下方的 **Assets** 中选择适合电脑的安装包：

| 你的电脑 | 选择的文件 |
|---|---|
| Mac，使用 Apple M 系列芯片 | 名称含 `mac-arm64` 的 `.dmg` |
| Mac，使用 Intel 处理器 | 名称含 `mac-x64` 的 `.dmg` |
| Windows，使用 Intel / AMD 64 位处理器 | 名称含 `win-x64` 的 `.exe` |

不确定 Mac 类型时，可以在苹果菜单的“关于本机”中查看芯片或处理器信息。下载页中的 **Source code** 是程序源码，普通用户选择上表中的安装包即可。

- **Mac**：打开 DMG，将 OfferDesk 拖入“应用程序”，再从“应用程序”打开。
- **Windows**：运行 EXE，按安装向导完成安装，再打开 OfferDesk。

Mac 安装包尚未获得 Apple Developer ID 认证和公证，系统可能提示开发者无法验证或阻止打开。确认安装包来自本项目发布页后，可在尝试打开后进入“系统设置 → 隐私与安全性”，查看是否有“仍要打开”按钮。若没有此按钮或仍然提示“已损坏”，请在 [问题反馈](https://github.com/mzh0221/offerdesk/issues) 中附上提示内容和系统版本。

2026-11-05 已为 v1.1.1 的 Mac 安装包补充免费 ad-hoc 完整性签名并替换下载文件；此前下载过该版本的用户请重新下载，校验时使用更新后的 SHA256SUMS.txt。

**v1.5.0**：AI 接入页重做为“连接工具 → 验证连接 → 开始采集”，选中工具后自动检测，配置写入后直接引导验证；服务自检收进故障排查。岗位导入会从原文补齐漏填字段，旧草稿与岗位支持“从原文补全”。详见 [本次更新说明](docs/release-notes.md)。

外部 AI 岗位导入统一使用 **本地 MCP**，支持 Codex、Claude、DSH、ZCode、WorkBuddy 和 OpenCode。连接步骤、逐项复制与检查提示词见 [MCP 配置指南](docs/import.md)。保留截图 OCR、手动填写和旧草稿。

v1.2.0 新增截图框选识别、小图放大与草稿自动保存/恢复，改进公司名提取、列表符号清理和重复条目去重，并优化小窗口与核对表单。

v1.1.2 改进岗位预填，支持分行字段和常见招聘页头部，减少漏填与误填。v1.1.1 开始以空白列表启动，不预装岗位数据。升级安装会保留本机已有记录。v1.1.0 新增本地中英文 OCR 和岗位预填。识别模型已包含在安装包中，无需 API 密钥，首次使用即可离线识别。

## 开始使用

### 1. 收集岗位

点击 **上传岗位截图**，选择、拖入或粘贴同一岗位的招聘截图。可以调整图片顺序，也可以移除不需要的图片。

- 支持 JPG、PNG、WebP。
- 每个岗位最多5张截图，每张不超过5 MB。
- 长图无法导入时，可以拆成几张较小的截图。

也可以点击 **手动录入**，直接填写岗位信息，或通过 **AI 采集与导入** 导入岗位。

### 2. 识别、核对并保存

点击 **离线识别截图**，等待逐张提取文字。识别原文可以修改，再点击 **根据文字预填**，核对公司、岗位、地点、薪资和要求。

也可以选择 **手动填写**。**公司和岗位名称必填**，其他没有写明的信息可以留空。

可以附上招聘原链接，方便以后核对。填写完成后，点击 **保存到岗位列表**。

OCR 支持简体中文和英文，引擎与模型随安装包附带，第一次使用也能离线识别。模糊文字、复杂排版可能识别有误；预填支持明确标签、分行字段以及常见招聘页的标题和信息栏，无法判断或冲突的信息会留空，请核对后保存。识别失败可重试，也可保留已完成的文字继续手动填写。重试失败截图时会保留你已经修改的原文；新识别出的文字单独展示，方便核对后复制。

### 3. 跟进投递

在列表中直接切换岗位状态：

**待投递 → 已投递 → 笔试 → 面试 → 已结束**

这些状态可以按实际情况自由调整。打开 **查看详情**，可以补充投递日期、修改岗位信息，并用备注记录面试时间、沟通结果或下一步安排。详情中的修改完成后，点击 **保存修改**。

岗位较多时，可以按公司、岗位或技能搜索，也可以结合城市、岗位类型和投递状态筛选。

### 4. 回看招聘信息

在详情中展开 **原始招聘信息**，可以查看保存的文字和截图，点击截图查看原图。点击 **招聘原页**，会使用系统浏览器打开招聘网站。

不再需要的岗位，可以在详情中选择 **删除岗位** 并确认；关联截图也会一并删除。

## 外部 AI 采集导入

点击 **AI 采集与导入**，通过卡片选择 Codex、Claude、DSH、ZCode、WorkBuddy 或 OpenCode，按“连接工具 → 验证连接 → 开始采集”完成接入：选中工具后自动检测，点击连接写入配置，再复制验证消息到 AI 工具实际调用；无法自动配置时可复制配置并查看手动步骤。采集结果先成为待核对草稿，确认后保存。详见 [MCP 配置指南](docs/import.md)。

## 数据保存在本机

正常关闭应用、重启电脑后，已经保存的岗位、投递状态、备注和截图仍会保留。日常录入、编辑和查看可以离线使用，打开外部招聘网站时需要网络。

数据不会自动上传，也不会同步到其他设备。可以通过应用菜单 **文件 → 打开数据目录** 查看保存位置：

| 系统 | 默认位置 |
|---|---|
| Mac | `~/Library/Application Support/OfferDesk/` |
| Windows | `%APPDATA%/OfferDesk/` |

请保留这个目录；手动删除它会同时删除本机记录。

## 更新与反馈

更新版本请前往 [下载页](https://github.com/mzh0221/offerdesk/releases)，选择对应系统的新安装包，退出 OfferDesk 后再安装。当前不支持自动更新。

遇到问题或有功能建议，可以在 [GitHub Issues](https://github.com/mzh0221/offerdesk/issues) 留言。描述问题时，附上电脑系统、应用版本和复现步骤；如果提供截图，请先遮挡个人信息。

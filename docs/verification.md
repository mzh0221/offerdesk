## 当前已知边界

- IndexedDB 按浏览器和站点地址隔离，不跨浏览器或设备同步；`localhost` 与 `127.0.0.1` 的数据不共享。
- 清除网站数据、无痕模式或更换浏览器可能使记录不可用，尚无备份功能。
- 当前标签页只保存最近一次导入的恢复入口；关闭标签页后不会自动恢复入口，不提供导入历史管理页。
- 退出导入时，尚未保存的人工修改不会持久化。
- 跨标签页同时修改同一岗位采用最后保存的版本。
- 当前本地模式只保存截图并支持手动填写，不能通过仅设置模型密钥启用识别。

## 审查问题修复（当前源码）

- 截图修改复用原草稿 ID；草稿文字和附件替换在单个 IndexedDB 事务中提交，移除图片立即更新草稿；写入失败保留原草稿。岗位及关联记录的删除也使用单个事务。
- OCR 部分失败重试保留人工修改；成功补识别的文字单独展示。重新识别全部图片前，对覆盖已修改原文进行确认。
- 详情和恢复导入的附件统一按 position 排序，使用随机 ID 测试确保顺序不依赖主键。
- 29项单元测试、类型检查、生产构建与4个桌面回归场景通过，覆盖模拟写入/删除失败回滚、截图替换后的关联删除、恢复和重启排序，以及真实 OCR 重试。
- 不更改数据库名、对象仓库、应用来源或用户已有数据格式。旧版本已经遗留的孤立草稿未自动清理，避免误删未完成录入。

修复后的 Mac arm64 实际应用包也已通过全部4个桌面场景，包括旧版 ASAR 写入数据后的升级读取、状态修改和关联删除。

## Mac 免费临时签名（当前源码）

- Mac 构建使用 `identity: "-"`，关闭公证，保留 Hardened Runtime，使用锁定的 electron-builder 默认 Electron 权限模板。
- 29项单元测试、类型检查、生产构建通过；工作流 YAML 可解析。
- 本机使用已安装的 Electron 45.2.3（构建参数 `-c.electronDist=node_modules/electron/dist`）生成 arm64 DMG 和 ZIP；无需下载证书或配置密钥。
- `codesign --verify --deep --strict` 通过，签名详情为 `Signature=adhoc`，标记包含 `adhoc,runtime`。打包后的应用通过全部4个桌面测试。
- DMG 的 `hdiutil verify` 校验通过；以只读方式挂载后，映像内应用的完整签名校验及全部4个桌面测试也通过，完成后已推出映像。
- Mac arm64、Mac x64、Windows x64 均已通过对应系统的测试、打包及实际应用验证；Mac 两种架构的完整签名和 ad-hoc 标记校验通过，见 [重新构建记录](https://github.com/mzh0221/offerdesk/actions/runs/42013823809)。
- v1.1.1 正式版的5个安装文件和 SHA256SUMS.txt 已替换，发布任务核对了 GitHub 资产摘要与构建校验和。发布源码提交为 `8be90d4`；此前下载的旧文件需要重新下载。
- 本地签名、启动和磁盘映像测试不代表 Gatekeeper 认可下载的应用；尚未提供 Apple 开发者身份认证或公证，首次下载后仍可能需要用户批准。

## 本地字段预填改进（v1.1.2 发布前验证）

- 针对原文基本正确但字段留空的问题，扩展标签别名、空格及分行字段、多字段同行、招聘页头部和明确要求语句解析；OCR 引擎与离线存储方式不变。
- 明确标签优先于版式推断，同级候选冲突时留空；从职位头部推断公司、岗位、薪资和城市，排除职责、公司介绍、福利及推荐岗位。技能与学历条件考虑否定语句和优先条件。
- 45项单元测试、类型检查、生产构建通过，测试覆盖无标签手机版式、日薪与 K/万月薪、多薪制、要求分区、否定和冲突等案例。
- 5个桌面场景通过，包括新增的真实窗口文字录入预填、核对修改、保存及重启后保留原文和字段；既有离线 OCR 与截图回归通过。未使用真实用户数据目录。
- 当前验证使用人工编写的招聘文本与合成截图，不构成真实招聘截图准确率测量；品牌简称、复杂混排、未知城市或标签仍可能漏填，需要结合实际失败原文继续评估。
- 以上改动尚未更新 GitHub 安装包。

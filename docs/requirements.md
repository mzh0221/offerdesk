# OfferDesk 开源桌面应用需求

更新日期：2026-11-05。目标：在 GitHub 以 MIT 许可证开源，提供可下载的 Mac 与 Windows 本地应用。应用和业务数据在本机运行；GitHub 用于源码协作和安装包分发，不提供在线岗位管理服务。

## 使用方式与范围

- 面向单人，下载安装桌面应用后直接打开，无需用户安装 Node.js、运行终端命令或启动浏览器服务。
- 首批平台为 Mac Apple Silicon、Mac Intel 和 Windows x64；分别生成 DMG/ZIP 和 EXE 安装包。
- 桌面入口复用现有 React 界面，通过 Electron 加载打包资源，不监听本地 HTTP 端口。
- 基础功能无需账户、邮箱邀请、云数据库、云存储或公网域名。
- 基础岗位管理与截图保存不依赖云服务；安装依赖和访问招聘来源链接可以需要网络。
- 数据保存在应用独立数据目录中的 IndexedDB；更新应用应保持数据目录和存储来源稳定，并支持完整备份与恢复。
- 桌面应用固定使用内部来源 offerdesk://app；网页开发版仍按浏览器地址隔离。网页旧数据不会自动进入桌面版，迁移需后续通过备份/导入完成。
- 源码仓库目标为 mzh0221/offerdesk；Git 管理源码，岗位与截图通过数据备份功能另行管理，个人数据和密钥不进入源码或安装包。
- GitHub Actions 在对应系统构建、测试安装包；发布版本附平台说明、校验和、已知限制和签名状态。
- 首次预览包可未签名，但必须清晰标记；广泛公开分发前完成 Mac 签名/公证及 Windows 签名方案。

## 核心功能

- 收集岗位：支持文字录入，以及同一岗位1—5张截图的上传、粘贴、排序和移除。
- 管理岗位：公司、职位、城市、薪资、技能、到岗条件、招聘链接、原文、截图、投递状态、日期和备注。
- 查找岗位：搜索、城市/状态/岗位类型筛选和分页。
- 维护记录：新增、查看、修改、删除，保存后刷新和重启服务仍能读取。
- 初始岗位：标明来源与核查日期，不伪造投递记录、不猜测未披露信息；数据批次更新保留用户修改和删除状态。
- 数据备份：导出、导入完整岗位数据及关联截图；导入须校验格式并提示冲突，不能悄悄覆盖现有记录。当前待实现。
- 截图识别：保留自动提取功能目标，模型方案待定，当前待实现。不得将示例结果冒充真实识别；缺失或冲突字段应提示人工核对，识别失败可继续手动填写。
- 本地交互：优先桌面使用，同时保留窄屏布局；弹窗可通过键盘操作，错误提示应明确且可恢复。

## 截图识别的约束

应用只在本机运行，与是否调用在线模型是两个独立选择。本次不指定必须使用在线模型或必须完全离线。

- 现有本地模式不调用模型；填写云模型密钥本身不会改变这一行为。
- 如采用在线模型，密钥仅由本机服务端读取，并在发起识别前说明需要向模型服务发送的招聘文字或截图；不要求先上传到云存储。
- 如采用本机模型，需另行说明模型安装、硬件和运行要求。
- 不因模型未配置而阻塞手动录入、截图保存或岗位管理。

## 本地完成标准

1. 用户下载安装后可以直接打开桌面应用，无 Node.js、终端操作或云服务配置时也能管理岗位。
2. 核心录入、筛选、修改、删除及截图功能经过实际浏览器验收。
3. 完全退出并重启应用、覆盖升级后，已保存的岗位、投递记录和截图仍可读取；卸载默认不主动删除数据目录。
4. 完整备份可在干净的浏览器存储中恢复，岗位、投递记录、原文和截图一致。
5. 截图识别实现后验证真实输入、输出核对及失败降级；未实现前明确说明状态。
6. 单元测试与类型检查通过；分别在 Mac 和 Windows 实际运行打包后的应用，并保留人工验收结果和已知限制。
7. GitHub 提供源码、MIT 许可证、贡献说明和可下载的安装包；发布前验证产物不含本地环境配置、用户岗位或私钥。

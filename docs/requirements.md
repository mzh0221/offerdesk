# OfferDesk 当前需求

更新日期：2026-11-12。项目定位为个人使用、在 GitHub 开源的 Mac / Windows 本地桌面应用。

## 保留的功能与交付

- 下载安装后直接打开，无需用户运行终端命令或配置服务。
- Mac 支持 Apple Silicon 与 Intel，提供 DMG / ZIP；Windows x64 提供 EXE 安装器。
- 单人使用，岗位、招聘原文、截图、投递状态、日期及备注保存在本机应用数据目录。
- 上传同一岗位1—5张截图，支持拖拽、粘贴、排序和移除；支持简体中文与英文本地 OCR，识别原文可编辑，再通过本地规则预填并人工核对；保留手动填写。
- 搜索、城市/状态/岗位类型筛选、分页、详情编辑与删除。
- 录入草稿自动保存在本机，支持退出重开后恢复、选择和丢弃；保留人工核对字段、链接、原文与截图。未保存的详情修改在关闭或重载前提供保护。
- 查看招聘原文、截图缩略图和原图；招聘来源链接由系统浏览器打开。
- 新安装时岗位列表保持空白；不预装演示岗位或招聘数据。已有用户数据在升级时保留。
- 关闭、重新打开应用后数据仍保留，升级应兼容现有记录。
- 源码以 MIT 许可证公开，保留本地 Git、GitHub Actions 测试及安装包分发。

## 本地存储约束

数据使用 IndexedDB，应用名为 OfferDesk，应用 ID 为 `io.github.mzh0221.offerdesk`，页面来源为 `offerdesk://app/`，数据库为 `offerdesk-local-v1`，对象仓库为 `records`。这些标识保持稳定。

当前只要求本地保存。导出备份、恢复、跨设备同步和旧网页数据迁移不属于当前必做功能。Git 只管理源码，不包含个人岗位和截图。

## 当前不包含

- 网站入口、网页登录、注册、邮箱邀请及多人权限。
- 云数据库、云存储、服务端 API、定时清理、公网部署及网站托管。
- 发行签名、公证、证书申请或自动更新。
- 简历改写、岗位匹配评分、自动投递。

截图识别采用随包内置的本地 OCR；不引入模型密钥、远程模型服务或就业建议功能。

## 验收标准

1. 无账户或额外服务配置时可以打开应用并管理岗位。
2. 截图识别、手动填写、AI 导入、搜索筛选、编辑、删除和查看原图能够实际完成。
3. 完全退出重启后，已保存的岗位、日期、备注和截图一致。
4. 旧版数据能够由清理后的版本继续读取。
5. 单元测试、类型检查和桌面构建通过；在目标系统启动打包后的应用进行验证。
6. 安装包和源码不包含个人数据、凭据或不使用的服务代码。

## 本地 OCR

模型随安装包附带，无首次下载。最多5张截图依次识别，可取消或重试失败截图。通过本地规则结合明确标签、分行字段和常见招聘页头部提取岗位信息；明确字段优先，无法判断或冲突的信息留空，职责、公司介绍和推荐岗位不用于推断当前岗位的公司、名称或薪资；保存前人工核对。原图、识别文字与预填结果保存在现有本地导入记录中，不接外部 API。

## 外部 AI 岗位导入

支持具备本地 STDIO MCP 能力的 AI harness 导入批量岗位，提供 WorkBuddy、DeepSeek Harness（Cordis 插件）、ZCode、Codex、Claude、Cursor、Gemini CLI、VS Code、Cline、OpenCode 配置模板与豆包工作的 JSON 文件交付提示词；增加 JSON 文件和本机 CLI 兼容入口，应用须已打开。采集和筛选由外部 AI 工具承担；OfferDesk 不内置爬虫或远程模型。每批最多50条，包含招聘正文、详情链接与字段；校验、去重后创建待核对草稿，人工确认后保存为正式岗位。MCP 通过受凭据保护的本机 IPC 接入，保留现有页面安全隔离和 IndexedDB 标识。旧数据无需迁移。配置与格式见 `docs/import.md`。

直接粘贴招聘文字的录入入口已移除。截图 OCR 的原文编辑与预填保留；既有文字草稿和外部 AI 导入草稿直接进入核对页面，保留原文和字段，不删除旧数据。

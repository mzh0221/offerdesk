# OfferDesk v1.3.0：AI 采集接入与导入流程调整

这次更新让外部 AI 工具采集到的岗位可以进入 OfferDesk，再由你核对保存。应用继续在本机保存岗位、截图和投递记录，无需注册 OfferDesk 账户。

## 本次主要变化

### 新增 AI 工具接入

首页新增 **AI 工具接入**，按当前应用安装位置生成配置，复制到对应 AI 工具后即可连接本地 MCP，不需要给 OfferDesk 配置模型密钥或另外安装 Node.js。

| 工具 | 本次提供的接入方式 |
|---|---|
| WorkBuddy（腾讯） | 本地 MCP 配置 |
| DeepSeek Harness（DSH） | Cordis 插件补丁 |
| ZCode（智谱） | 启用 MCP 的运行配置 |
| Codex、Claude Code / Desktop、Cursor、Gemini CLI、Cline、VS Code | 对应格式的本地 MCP 配置 |
| OpenCode | 分别提供 V1、V2 配置 |
| 豆包工作 | 专用采集提示词、JSON 示例和文件导入 |

这些是按各工具配置格式提供的接入模板，不代表所有客户端版本都已逐个安装实测。豆包工作本次使用文件导入，不提供云端直接连接本机的能力。

### 三种岗位导入方式

- **MCP 自动导入**：AI 调用 `get_import_spec` 查看格式，再调用 `import_jobs` 将岗位导入待核对草稿。AI 工具与 OfferDesk 需在同一台电脑运行，导入时保持应用打开。
- **JSON 文件导入**：让 AI 生成岗位 JSON 文件，在 **AI 工具接入 → 选择岗位 JSON 文件** 中导入。适合豆包工作或无法连接本地 MCP 的工具。
- **CLI 自动导入**：有本机命令执行能力的工具可使用 `--offerdesk-import` 导入文件，也可从标准输入读取 JSON。

每批最多 **50 条**，请求或文件不超过 **4MB**。保留岗位详情链接、招聘原文与提取字段；逐条返回创建、重复或校验失败结果。缺失必填字段的条目会报错，不影响同批其他合法岗位。

同一来源链接会进行去重，已有内容不被覆盖；支持使用相同批次标识和内容安全重试，存储写入失败时整批回滚。不同链接的相同岗位仍可能需要人工去重。

### 调整岗位录入入口

**移除了“文字录入”和“粘贴文字”入口。** 现在可以选择截图识别、手动填写，或由 AI 工具导入。

- 截图 OCR 仍支持离线中英文识别、框选区域、识别原文编辑和字段预填。
- 已有文字草稿不会删除，继续编辑时直接进入核对页面，保留原文和已填字段。
- AI 导入结果先进入 **外部导入待核对**，点击 **核对岗位** 后保存为正式岗位；不会自动投递。

### 整理项目与文档

新增简明的 [AI 岗位导入上手指南](https://github.com/mzh0221/offerdesk/blob/v1.3.0/docs/import.md)，统一配置、使用步骤和常见问题。移除应用已不再使用的岗位预置模块与对应测试，将历史检查记录归档。这些源码清理不会删除已有用户数据。

## 第一次使用 AI 导入

1. 打开 OfferDesk，点击 **AI 工具接入**，选择你的工具。
2. 复制配置，按窗口提示合并到 AI 工具的配置中，再重新连接。
3. 告诉 AI：

   > 请查找符合我条件的岗位，先调用 OfferDesk 的 get_import_spec，再读取招聘详情并用 import_jobs 导入。保留原文和来源链接，缺失信息留空，不编造、不自动投递。

4. 回到 OfferDesk，在 **外部导入待核对** 中检查并保存。

豆包工作用户在接入窗口复制 **采集任务提示词**，让豆包生成 `jobs.json`，下载后选择文件导入即可。

MCP 只提供导入能力，岗位搜索与网页读取由外部 AI 工具完成；登录限制、验证码或网站变化可能使采集失败。外部 AI 的费用和数据处理方式由所选工具决定，OfferDesk 不内置远程模型服务。

## 升级与数据

先保存未完成的修改，完全退出旧版，再覆盖安装新版。应用名、应用 ID、内部来源和 IndexedDB 标识保持不变，已有岗位、投递状态、备注、截图及草稿继续保留，无需手动迁移。

首次安装仍为空白列表。岗位管理和截图 OCR 可离线使用；外部 AI 采集及打开招聘网站是否需要网络，取决于对应工具和网站。

## 下载与安装

在下方 **Assets** 中选择适合电脑的安装包：

| 电脑 | 安装包 |
|---|---|
| Mac，Apple M 系列芯片 | `OfferDesk-1.3.0-mac-arm64.dmg` |
| Mac，Intel 处理器 | `OfferDesk-1.3.0-mac-x64.dmg` |
| Windows，Intel / AMD 64 位处理器 | `OfferDesk-1.3.0-win-x64.exe` |

Mac 另提供 ZIP。`SHA256SUMS.txt` 用于核对下载文件完整性。

- **Mac**：打开 DMG，将 OfferDesk 拖入“应用程序”，再打开应用。
- **Windows**：运行 EXE，按安装向导完成安装。

安装包由对应系统的 GitHub Actions runner 构建，发布前检查单元测试、类型、桌面流程及打包后应用。回归覆盖截图 OCR、手动填写、旧草稿恢复、岗位持久化、MCP/JSON/CLI 导入、去重、重试和失败回滚。

Mac 包使用免费 ad-hoc 完整性签名，尚未提供 Apple Developer ID、公证或 Windows 发行证书。首次打开可能出现系统安全提示；确认文件来自本项目后，Mac 用户可在尝试打开后进入“系统设置 → 隐私与安全性”，查看“仍要打开”。

遇到问题请在 [GitHub Issues](https://github.com/mzh0221/offerdesk/issues) 附上系统、应用版本、所用 AI 工具及复现步骤，截图前遮挡个人信息。

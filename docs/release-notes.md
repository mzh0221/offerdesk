# OfferDesk v1.4.0：全新界面与本机 MCP 自动配置

本次更新让 AI 岗位采集成为首页主入口，并减少连接本机 MCP 时需要手动填写的内容。外部 AI 采集结果仍先进入待核对草稿，由你确认后保存；岗位、截图和投递记录继续保存在本机。

## 全新界面与动效

- 统一暖米白背景、深墨色文字、陶土色强调，以及标题、按钮、边框和留白。
- 首页突出“AI 采集与导入”，截图 OCR 和手动录入作为辅助入口；合并重复的说明入口。
- 将冗长的 AI 工具下拉菜单改为六张卡片：Codex、Claude、DSH、ZCode、WorkBuddy、OpenCode。
- 统一岗位列表、核对表单、详情页和接入窗口，调整小窗口布局，保持保存操作可见。
- 增加页面分层入场、弹窗展开、卡片悬停、按钮按压、配置切换与成功提示的短动效。开启系统“减少动态效果”后会停用这些动效。

## 本机 MCP 自动配置

打开 **AI 采集与导入 → 选择工具 → 检测并预览 → 写入配置并检查**。

检测阶段显示目标位置和写入方式，确认后才修改本机配置。写入会保留其他服务器和模型设置；如果配置在预览后被其他程序修改，会停止写入并要求重新检测。不会强制重启正在工作的 AI 客户端。

| 工具 | 本次自动配置方式与条件 |
|---|---|
| Codex | 检测可直接运行的官方 Codex CLI，注册用户级 MCP，再回读 OfferDesk 条目核对命令和参数；未找到 CLI 时可使用手动表单 |
| Claude Code | 合并用户级 `~/.claude.json`；需要先启动过该客户端 |
| Claude Desktop | 合并本机 `claude_desktop_config.json`；需要先启动过该客户端 |
| WorkBuddy | 合并已存在的默认 `~/.workbuddy/mcp.json`；自定义位置使用手动配置 |
| ZCode | 合并用户配置中的 OfferDesk 条目，同时开启 `features.mcp` |
| OpenCode V2 | 优先调用官方 CLI 注册用户级 MCP；没有 CLI 时，可合并现有用户目录中的标准 JSON 配置 |
| DSH / DeepSeek Harness | 仍需将 Cordis 补丁加载到指定会话，窗口提供保存与加载步骤 |

无法安全自动处理的格式、链接文件或有歧义的配置会保留原样，并提示使用手动方式。OpenCode 的 JSONC 可由其官方 CLI 处理。工具未安装或尚未完成首次设置时，先打开工具再检测。

**“配置已写入”和“MCP 服务自检通过”不等于 AI 客户端已经连接。** 自检会实际启动 OfferDesk 的 MCP 子进程，完成握手、读取工具列表并调用只读的 `get_import_spec`，不会创建岗位或草稿。配置完成后，仍需在 AI 工具中重新加载 MCP 或新开会话，再用检查提示词确认真实工具调用。

已验证配置生成、本地合并、既有配置保护及 MCP 协议流程；这些接入模板不代表所有 AI 客户端版本都已逐一安装实测。

## 配置说明更清楚，复制按钮可直接使用

展开 **手动配置与参数**，可查看每个工具的具体步骤与配置文件位置。

- STDIO 表单明确列出名称、启动命令、每一项参数、环境变量与工作目录，并按当前应用位置生成实际值。
- 启动命令和参数支持分别复制，保留中文、空格与 Windows 路径；避免将整段 JSON 或数组填进命令栏。
- 提供只读的连接检查提示词，以及可修改岗位、城市和条件的采集任务提示词。
- 修复安全权限导致网页剪贴板写入失败的问题。桌面复制接口仅接受接入页提供的配置与提示词，页面仍没有 Node.js 权限。

完整步骤见 [MCP 配置指南](https://github.com/mzh0221/offerdesk/blob/v1.4.0/docs/import.md)。

## 外部 AI 导入统一为 MCP

**相较 v1.3.0，本版移除了豆包工作入口、JSON 岗位文件导入和 CLI 文件导入。** 旧的 `--offerdesk-import` 文件导入命令会明确提示功能已移除，并以非零退出码结束；请将旧脚本改为 MCP 调用。

外部 AI 应先调用 `get_import_spec` 获取格式，再调用 `import_jobs`。每批最多 **50 条、4MB**，保留来源链接、招聘原文与字段。校验、去重、同批重试和待核对保存流程继续保留；不会自动投递。

截图 OCR、手动录入、岗位管理和投递跟进继续可用。MCP 本身负责导入，岗位搜索与网页读取由所选 AI 工具承担；OfferDesk 不内置远程模型或爬虫。

## 升级与已有数据

保存未完成修改，完全退出旧版，再覆盖安装新版。应用名、应用 ID、内部页面来源与 IndexedDB 标识保持不变，已有岗位、投递状态、备注、截图和历史草稿继续保留，无需手动迁移。

首次安装仍从空白列表开始。本机岗位管理和内置 OCR 可离线运行；AI 工具采集网页是否需要网络，取决于所选工具与网站。导入期间请保持 OfferDesk 打开，并在同一台电脑上运行 AI 工具。

## 下载与验证

在下方 **Assets** 中选择对应安装包：

| 电脑 | 安装包 |
|---|---|
| Mac，Apple M 系列芯片 | `OfferDesk-1.4.0-mac-arm64.dmg` |
| Mac，Intel 处理器 | `OfferDesk-1.4.0-mac-x64.dmg` |
| Windows，Intel / AMD 64 位处理器 | `OfferDesk-1.4.0-win-x64.exe` |

Mac 另提供 ZIP，`SHA256SUMS.txt` 用于核对文件完整性。安装包由对应系统的 GitHub Actions runner 构建，流程包含单元测试、类型检查、桌面测试、打包及打包后应用验证。

验证覆盖配置预览与写入、其他设置保留、过期预览拒绝、只读自检、复制限制、MCP 导入、去重和重试，以及 OCR、手动填写、旧草稿、数据持久化、小窗口和减少动态效果模式。

Mac 包沿用免费 ad-hoc 完整性签名，未提供 Apple Developer ID、公证或 Windows 发行证书。遇到问题请在 [GitHub Issues](https://github.com/mzh0221/offerdesk/issues) 附上系统、应用版本、AI 工具与复现步骤。

# OfferDesk v1.5.1：更直观的 AI 接入与岗位信息补全

本版重新设计“AI 采集与导入”，减少配置时需要理解的参数与状态；同时修复招聘原文已有要求、导入后却显示空白的问题。已有岗位、草稿、截图和投递记录继续保存在本机。

## 三步完成 AI 接入

打开 **AI 采集与导入**，按以下步骤操作：

1. **连接工具**：选择 Codex、Claude、DSH、ZCode、WorkBuddy 或 OpenCode。选中后自动检测可用配置，显示写入位置；点击 **连接工具名称** 才会写入。Claude 可选 Code / Desktop。已有配置可直接进入验证。
2. **验证连接**：配置写入后自动进入此步。重新加载 AI 工具的 MCP 连接，点击 **复制验证提示词**，到 AI 对话粘贴发送。看到实际工具调用返回 `version: 1`、每批最多 `50` 条，再点击 **我已验证，下一步**。
3. **开始采集**：点击 **复制采集任务**，到 AI 对话修改岗位、城市和筛选条件后发送。AI 导入后，回到首页待核对草稿确认保存。

- 六个工具改为紧凑选项，每一步突出主要操作，减少长文档和重复提示。
- 无法自动配置时，提供 **复制 MCP 配置**（DSH 为 Cordis 补丁），并展开相应手动步骤。
- 命令、参数、完整配置及故障排查默认折叠，需要时再展开。
- 调整小窗口布局、步骤切换时的焦点与滚动位置，并保留系统“减少动态效果”支持。
- 自动检测为只读操作；快速切换工具时会忽略旧检测结果，避免串用其他客户端的配置。
- 写入继续保留其他服务器和模型设置；检测后配置发生变化时停止写入，需重新检测。

自动配置适用范围与 v1.4.0 一致：Codex 需要可直接运行的官方 CLI；Claude、WorkBuddy、ZCode 使用对应用户配置；OpenCode 优先使用官方 CLI；DSH 需要在目标会话中加载补丁。模板不代表所有客户端版本均已逐一安装实测。完整说明见 [MCP 配置指南](https://github.com/mzh0221/offerdesk/blob/v1.5.1/docs/import.md)。

## 服务自检不再占用正常接入流程

**配置写入后不再自动执行 MCP 服务自检。** 主流程中的独立自检按钮和结果已移入默认折叠的 **连接故障排查**，仅由用户主动触发。

服务自检只验证 OfferDesk 自己的本机服务，不能判断 Codex、ZCode 等工具是否打开或连接；它也不会导入岗位。正常接入直接在 AI 工具中发送验证消息即可。

**“配置已写入”不等于“AI 已连接”。** 本版不把配置成功或本机自检结果标记为客户端已连接。“我已验证”由你根据 AI 的实际调用结果确认，应用尚未自动接收客户端验证回执。

若客户端返回 `Transport closed`，需重新加载或重启该 MCP 连接，再重新验证；本次更新不保证自动修复客户端已关闭的旧连接。源码版和安装版应使用各自生成的启动命令，应用移动位置后需重新配置。

## 自动补齐招聘原文中漏填的信息

此前 AI 即使提交了完整招聘原文，只要没有单独填写 `required`、`preferred`、`availability`，应用仍会保存为空。本版在导入时增加本地原文补提取：

- 补充必备技能与任职要求、加分与优先条件、出勤与到岗安排，以及空缺的地点、薪资、学历、毕业届别、实习时长、每周到岗和岗位类型。
- 已填标量值保留；部分填写的列表可追加遗漏条目并去重，重复补全不会反复添加。
- 支持常见中英文栏目、Markdown 标题和列表；区分必备要求、优先条件、岗位职责、福利及推荐职位。
- 按明确证据提取，原文未说明或有歧义时保持为空；保存的完整原文继续可核对。
- MCP 字段说明与采集提示词要求完整读取岗位详情、逐项填写，并保留原句和限定条件；不只读取搜索摘要。

导入回执中的 `filled_fields` 表示应用补充过的字段，`warnings` 提醒仍为空的要求或超过限制的内容。每类要求最多40项、单项2000字，技能标签最多15项；每批仍最多50条、4MB。超过结构化字段限制时提示核对，完整招聘原文仍保留在记录中。

## 旧草稿和已有岗位也能补全

在 **核对岗位** 或 **岗位详情** 点击 **从原文补全**，检查结果后保存。人工填写的内容、备注和投递状态保留；详情中的补全修改可取消，保存后重启仍保留。

不会在打开记录时自动改写历史数据，也不会重新访问原网页。如果当初只保存了摘要，需重新读取完整招聘信息后补充；重复导入同一链接仍会去重，不会覆盖已有岗位。

## 升级与下载

保存未完成修改，完全退出旧版后覆盖安装。应用名、应用 ID、内部页面来源、IndexedDB 数据库与对象仓库标识均保持不变，无需手动迁移。

| 系统 | 安装包 |
|---|---|
| Mac，Apple M 系列芯片 | `OfferDesk-1.5.1-mac-arm64.dmg` |
| Mac，Intel 处理器 | `OfferDesk-1.5.1-mac-x64.dmg` |
| Windows，Intel / AMD 64 位处理器 | `OfferDesk-1.5.1-win-x64.exe` |

Mac 另提供 ZIP，`SHA256SUMS.txt` 用于核对文件完整性。安装包由对应系统的 GitHub Actions runner 构建，包含单元测试、类型检查、桌面测试、打包后应用验证和发布文件校验。

验证覆盖三步接入、配置保护、工具切换竞态、复制限制、手动故障排查、原文补全、旧记录保存与撤销、MCP 导入和去重重试，以及 OCR、数据持久化、小窗口和减少动态效果模式。

Mac 包沿用 ad-hoc 完整性签名，未提供 Apple Developer ID、公证或 Windows 发行证书。反馈问题请在 [GitHub Issues](https://github.com/mzh0221/offerdesk/issues) 附上应用版本、系统、AI 工具和复现步骤。
